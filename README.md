# Netsody Homebrew Packages

This tap contains the following formulas and casks.

## Install

### Netsody Agent
`brew install netsody/tap/netsody`

### Netsody UI (macOS App)
`brew install --no-quarantine netsody/tap/netsody-ui`

## Upgrade

### Netsody Agent
`brew upgrade netsody/tap/netsody`

### Netsody UI (macOS App)
`brew upgrade --no-quarantine netsody/tap/netsody-ui`
